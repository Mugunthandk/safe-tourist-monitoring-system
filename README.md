# SafeGuard Tourist Monitoring System

## Environment Variables
- `GEMINI_API_KEY`: Required for AI-assisted incident analysis (optional).
- `JWT_SECRET`: Secret for authentication tokens.
- `APP_URL`: Base URL of the application.

## Setup
1. `npm install`
2. `npm run dev`

## Features
- **Tourist App**: Location tracking, SOS button, Safety Heatmap.
- **Admin Dashboard**: Real-time map monitoring, Geo-fencing management, Incident response.
- **AI Engine**: Movement speed and risk zone detection.
- **Blockchain ID**: Digital ID verification via hashing.
